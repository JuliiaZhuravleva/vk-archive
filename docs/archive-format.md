# Формат GDPR-экспорта VK

Всё ниже — ПРОВЕРЕНО непосредственно на живом экспорте (август 2025),
если не отмечено иначе.

## Общее

- Архив = zip со статическими HTML-страницами + один `style.css`. **Никаких
  JSON/XML и никаких медиафайлов внутри** — только HTML со ссылками.
- Кодировка всех HTML — **windows-1251** (`<meta charset="windows-1251">`).
- Точка входа: `index.html` (крошки-навигация по разделам).

## Разделы верхнего уровня

| Папка | Содержимое |
|---|---|
| `messages/` | переписки: `<peer_id>/messages<N>.html` + `index-messages.html` |
| `wall/` | посты стены, по одному каталогу на пост |
| `photos/` | фото-альбомы и комментарии к фото (ссылки, не файлы) |
| `audio/` | аудио-альбомы (списки треков) |
| `video/` | видео (ссылки) |
| `likes/`, `comments/`, `bookmarks/` | активность |
| `profile/` | страница, друзья, смены имени/телефона/почты, подарки, чёрный список |
| `ads/`, `apps/`, `payments/`, `sessions/`, `verification/`, `other/` | служебное |

## Формат сообщений

- `messages/index-messages.html` — список всех диалогов: `peer_id` → имя
  собеседника/чата — по записи на диалог.
- `peer_id`: положительный = пользователь, отрицательный = сообщество,
  `2000000000+` = групповой чат.
- Каждый диалог разбит на страницы `messages0.html`, `messages50.html`, … —
  нумерация по смещению, новые сообщения в начале.
- Одно сообщение:

```html
<div class="message" data-id="999110">
  <div class="message__header"><a href="https://vk.com/id...">Имя</a>, 27 дек 2018 в 0:58:19</div>
  <div>текст сообщения<div class="kludges">...вложения...</div></div>
</div>
```

- Свои сообщения — без ссылки в заголовке, просто `Вы, <дата>`.
- Даты в русском формате: `27 дек 2018 в 0:58:19` (месяцы: янв фев мар апр мая
  июн июл авг сен окт ноя дек).
- Вложения внутри `<div class="kludges">`:

```html
<div class="attachment">
  <div class="attachment__description">Фотография</div>
  <a class='attachment__link' href='https://...'>https://...</a>
</div>
```

## Типы вложений (полный перечень)

`Фотография`, `Стикер`, `Запись на стене`, `Файл`, `Видеозапись`, `Аудиозапись`,
`Ссылка`, `Подарок`, `N прикреплённых сообщений`, `Комментарий на стене`,
`История`, `Плейлист`, `Опрос`, `Карта`, `Статья`, `Звонок`, `Товар`, `Группа`,
`Сообщение удалено`, `Подкаст`, `Момент`, `Денежный перевод`, `Маска` и др.

## Голосовые сообщения ⚠️

- Отдельного типа «Голосовое сообщение» в экспорте НЕТ. Голосовые лежат под
  типом **«Файл»** со ссылкой вида
  `https://psv4.userapi.com/s/v1/amsg/<hash>.ogg` (`amsg` = audio message).
- Сами ogg-файлы в архив не включены — только ссылки.
- Ссылки подписанные, но на 30.07.2026 работают **без авторизации** (проверено
  curl'ом, HTTP 206). Срок жизни не документирован — качать как можно скорее.
- «Аудиозапись» (музыка) — вообще без ссылок, содержимое недоступно.
- «Файл» без ссылки — удалённые или недоступные документы.

## Прочие наблюдения

- Фото-ссылки (`sun*.userapi.com/...jpg?...&sign=...`) тоже живы (проверено).
- Подпись (`sign=`) вшита в URL — работает без cookies.
- Тексты содержат HTML-сущности (`&#33;`, `&#128526;`) — при парсинге нужен
  `html.unescape`.

## Гочи инструментов

- macOS BSD `grep` трактует cp1251-HTML как бинарные файлы: без `-a` молча
  пропускает, а классы `[^<]` не матчат байты ≥ 0x80 даже с `LC_ALL=C`.
  **Вывод: для поиска/парсинга использовать Python** (`bytes.decode('cp1251')`).
