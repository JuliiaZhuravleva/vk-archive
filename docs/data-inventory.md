# Инвентарь данных архива

Что лежит в GDPR-выгрузке ВКонтакте и что из этого вообще можно восстановить.
Всё ниже посчитано скриптами по живому экспорту (`Archive*.zip`, голый HTML,
выгрузка от августа 2025). Абсолютные числа конкретного архива не приводятся —
счётчики по собственной переписке сами по себе рассказывают о жизни владельца
больше, чем стоит публиковать; вместо них порядки величин и доли, по которым
видно, на какой масштаб рассчитаны скрипты.

## Сообщения — главный корпус

Порядка миллиона с лишним сообщений в тысяче с лишним диалогов, разложенных
по десяткам тысяч HTML-файлов. Личные диалоги, сообщества и групповые чаты
(`peer_id ≥ 2000000000`) лежат вперемешку в одном разделе.

### Распределение по годам

Крайне неравномерное — на пиковый год приходится больше сообщений, чем на
первые пять лет вместе, а хвост последних лет тонкий. Практический вывод один:
**оценивать объём работы по среднему за год бессмысленно**, ETA любого прогона
надо считать по конкретному диапазону дат.

Своё распределение — после импорта:

```sql
SELECT extract(year from sent_at) AS y, count(*)
  FROM messages GROUP BY y ORDER BY y;
```

### Топ диалогов по объёму

Распределение перекошено ещё сильнее, чем по годам: несколько самых крупных
групповых чатов и личных переписок дают вместе около трети всего корпуса,
а длинный хвост из сотен диалогов — единицы процентов. Отсюда два следствия
для пайплайна: любой полный прогон упирается в два-три диалога, и они же
первыми ловят все проблемы с памятью и таймаутами.

Конкретные `peer_id` и имена не приводятся: это персональные данные третьих
лиц. Свой список — в `data/raw/messages/index-messages.html` и в таблице
`dialogs` после импорта.

### Вложения в сообщениях

Доля — от общего числа вложений; она устойчивее абсолютных чисел и по ней
понятно, что имеет смысл качать.

| Тип | Доля | Контент доступен? |
|---|---|---|
| Прикреплённые сообщения | ~40% | текст внутри HTML, качать нечего |
| Фотография | ~⅓ | ссылки живы → качать |
| Стикер | ~12% | — (не нужен) |
| Запись на стене | ~5% | ссылка на пост |
| Файл | ~3% | бо́льшая часть — голосовые (.ogg, живы); остальные без ссылки |
| Видеозапись | ~3% | ссылки на vk.com/video |
| Аудиозапись (музыка) | ~2% | ссылок нет — потеряно |
| Ссылка | ~1% | URL в тексте |
| Подарок / История / Опрос / Карта / Звонок / пр. | < 1% | частично |

## Голосовые сообщения

Самое ценное и самое хрупкое: в архиве только ссылки вида
`psv4.userapi.com/s/v1/amsg/*.ogg`, файлов нет. На середину 2026 года
скачиваются без авторизации (HTTP 206 проверен), но срок жизни ссылок
неизвестен — качать в первую очередь. Восстановление содержимого — скачивание
плюс транскрипция (Whisper).

## Остальные разделы

| Раздел | Что внутри |
|---|---|
| Стена (`wall/`) | посты, сотни или тысячи в зависимости от активности |
| Фото (`photos/`) | страницы альбомов и комментарии к фотографиям |
| Аудио-альбомы (`audio/`) | только названия треков, файлов нет |
| Видео (`video/`) | страницы со ссылками |
| Комментарии (`comments/`) | комментарии к чужим записям |
| Лайки (`likes/`) | что лайкали, со ссылками |
| Профиль (`profile/`) | друзья, смены имени/телефона/почты, подарки, истории, чёрный список |
| Служебные | ads, apps, payments, sessions, verification, bookmarks, other |

Смены имени в `profile/` — недооценённый раздел: это датированные точки,
скелет биографии, по которому потом сверяется хронология.

## Чего в архиве НЕТ

- Медиафайлов (фото/аудио/видео/документы) — только ссылки
- Музыки («Аудиозапись» без ссылок) и файлов-вложений без ссылок
- Удалённых сообщений — на их месте заглушка «Сообщение удалено»
- E2E-чатов и того, что VK не включает в экспорт
